# Дневник давления

Все записи вымышлены. Версия 2026-09-11.1.

Шесть вымышленных измерений

Создано НЕЙРОПРОФИ специально для учебных квестов. Не содержит записей реальных людей.

Можно копировать и адаптировать для учебных и демонстрационных проектов. Сохраняйте пометку о вымышленных данных. Не используйте как отзыв, медицинский документ или подтверждение результата.

## Как использовать

Скачайте https://ezhgenti.ru/data/sets/pressure-diary/dataset.json. Импортируйте по id в отдельный учебный режим без замены личных записей. reference_date = 2026-10-05. Все суммы в рублях. Дополнительные файлы лежат в той же папке. Набор не содержит исходников закрытых проектов, настоящих токенов и доступов.

## Проверить

- Действие: Сохранить запись 120/80, пульс 70 и открыть её снова
  Ожидается: Все три числа, дата и единицы сохранены; нет диагноза
- Действие: Повторно открыть проект после сохранения
  Ожидается: Учебные записи сохранены; личные записи не заменены; повторный импорт не создаёт дублей

- Числа и диапазоны придуманы только для проверки интерфейса и импорта. Они не являются медицинскими рекомендациями.
- Не ставить диагнозы, не назначать лечение. Не загружать настоящие документы в публичный хаб.
