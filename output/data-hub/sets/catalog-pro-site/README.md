# Каталог или небольшой магазин

Все записи вымышлены. Версия 2026-09-11.1.

Бумажная мастерская: содержание для страницы

Создано НЕЙРОПРОФИ специально для учебных квестов. Не содержит записей реальных людей.

Можно копировать и адаптировать для учебных и демонстрационных проектов. Сохраняйте пометку о вымышленных данных. Не используйте как отзыв, медицинский документ или подтверждение результата.

## Как использовать

Скачайте https://ezhgenti.ru/data/sets/catalog-pro-site/dataset.json. Импортируйте по id в отдельный учебный режим без замены личных записей. reference_date = 2026-10-05. Все суммы в рублях. Дополнительные файлы лежат в той же папке. Набор не содержит исходников закрытых проектов, настоящих токенов и доступов.

## Проверить

- Действие: Положить в корзину два блокнота «Утро» и набор открыток
  Ожидается: Итого 1250 ₽; товар с нулевым остатком нельзя заказать; реальная оплата отключена
- Действие: Повторно открыть проект после сохранения
  Ожидается: Учебные записи сохранены; личные записи не заменены; повторный импорт не создаёт дублей

- Цены, персонажи, услуги и результаты вымышлены. Оплата и реальные рассылки не подключены.
