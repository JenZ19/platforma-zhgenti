# Примеры результатов учебных комплектов

Дата: 2026-09-08.

- `carousel-agent-v1/result-preview.png`: четыре PNG, созданные оригинальным генератором каруселей. Контактный лист показывает их целиком.
- `threads-agent-v1/result-preview.png`: лист просмотра настоящего сохранённого учебного черновика из `study.sqlite3`. Это не интерфейс Telegram и не результат генерации ИИ. Сам текст фиксированный и вымышленный.
- `webinar-moderator-agent-v1/result-preview.png`: лист просмотра вывода оригинальной проверки правил и поиска FAQ. Это не интерфейс Telegram или вебинарной комнаты. Внешние подключения не запускались.
- `family-health-hub-v1/labs-preview.png`: настоящий экран «Все анализы» запущенного учебного хаба. Две записи получены импортом вымышленного PDF через оригинальный обработчик.

Не использовать эти листы как доказательство подключённых Telegram-агентов. Для таких скриншотов потребуется отдельный учебный запуск с подключением Telegram и, где нужно, ИИ.

Технический кадр `family-health-hub-v1/result-preview.png` не предназначен для урока: встроенный PDF-просмотрщик в headless-браузере показал чёрную область. Для показа выбран реальный экран анализов без встроенного PDF. Исходная страница не изменялась и изображение не ретушировалось.

Проверено: оба теста оформления прошли; листы не имеют горизонтального переполнения; две числовые записи после импорта сохранены; повторная загрузка PDF распознана как дубликат. Скриншоты просмотрены визуально.

Материалы созданы локально. В платформу и опубликованные ZIP-комплекты в этой задаче не добавлялись.
