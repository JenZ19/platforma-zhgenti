# Границы учебного проекта

Работай с существующим index.html. Не генерируй другой проект вместо этой основы и не перезаписывай соседние папки.
Сохрани добавление, дату, одно главное дело на день, отменяемую отметку, перенос на завтра, редактирование и копии.
Не меняй ключи localStorage и не стирай записи без явного запроса. Режимы demo и real хранятся раздельно.
Настоящие дела пользователь вводит в форме, не проси их в чате. Нет внешних запросов или API.
Перед публикацией создай отдельную демонстрацию без личных копий. Не публикуй без подтверждения. Назови проверенные и непроверенные функции.
