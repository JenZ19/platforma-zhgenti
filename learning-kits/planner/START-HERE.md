# Планер: готовая учебная основа

Версия 2026-09-09.1. Оригинальная разработка для курса НЕЙРОПРОФИ.

1. Распакуйте ZIP. Внутри папка `planner` и файл `index.html` — это весь работающий планер.
2. Откройте папку `planner` в Codex. Отправьте первую команду из квеста. Codex запустит предпросмотр; самостоятельно создавать файлы не нужно.
3. По умолчанию показаны два вымышленных дела. Кнопка «Мой пустой планер» открывает отдельный личный список. Она не удаляет учебные записи.
4. Продолжайте менять эту копию в одном разговоре Codex. Сохраняйте прежние записи и проверяйте кнопки после каждого изменения.

Для телефона: прикрепите ZIP своему выданному помощнику школы. Он должен уметь распаковать проект и дать доступный HTTPS-предпросмотр. Если не умеет — обратитесь к куратору, не покупайте случайные сервисы.

Планер работает без API и подписок. Записи остаются в браузере на этом устройстве. Смена адреса предпросмотра или очистка браузера может сделать их недоступными: заранее нажмите «Запасная копия» → «Скачать копию». Для переноса используйте восстановление из этой копии.

Этот комплект не включает аккаунты, уведомления, публикацию, синхронизацию и интеграции календаря. Учебный пример на сайте не равен вашей отдельной опубликованной версии.

Код можно изменять и использовать в своих и клиентских проектах. Не переносите личные записи в публичные демонстрации.
