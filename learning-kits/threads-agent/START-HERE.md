# Threads-agent: учебный комплект

Это очищенная рабочая копия авторского threads-agent: здесь есть исходные правила, хранилище, загрузка источников, ИИ-генерация, ручная выдача черновиков и Telegram-бот. Личных данных, боевых адресатов, ключей, базы и источников оригинала нет.

## Начните с Codex

Передайте Codex эту папку и отправьте ему одним сообщением:

> Изучи AGENTS.md и START-HERE.md. Установи этот оригинальный Threads-agent для моего одного канала. Сначала прогони офлайн-проверку, затем помоги мне заполнить тему, стиль и собственные доступы. Никого не добавляй в адресаты и ничего не публикуй, пока я сама явно не подтвержу тестовую цель и первую отправку. Авторассылку не включай.

## Безопасная проверка

Эти команды нужны Codex для проверки:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python study_check.py
```

Полная проверка тестов:

```bash
.venv/bin/python -m pytest -q tests/test_study.py
```

Команда без сети разберёт заранее записанный учебный JSON исходным `compose.py`, оформит черновик и запишет его исходным `kb.py` в новую локальную базу `study-data/study.sqlite3`. Надпись `fixed educational example, not AI-generated` означает, что текст не создавался ИИ. Повторный запуск не перезаписывает существующую базу: Codex должен выбрать новую пустую учебную папку.

## Что можно менять

- Замените вымышленную тему, стиль и углы в `channels.yml` на свои.
- Сохраняйте только факты, которые можно проверить. Не добавляйте клиентские истории без разрешения.
- `sources.yml` намеренно пуст: учебная проверка ничего не скачивает.

## Настоящий запуск

Сетевые модули сохранены, но без ваших ключей и `ALLOW_LIVE_MODE=true` запуски `bot.py` и `generate.py` останавливаются до любой сети. Telegram-бот также не запустится без вашего числового `OWNER_USER_ID`; все сообщения и кнопки от других Telegram-пользователей отклоняются. Любое добавление адресата или публикация требуют вашего отдельного явного подтверждения. До этого `ALLOW_LIVE_MODE=false`, `OWNER_USER_ID=0`, а канал `enabled: false`.

Если ученица работает только с телефона, нужен школьный помощник на сервере: `localhost` на телефоне эту папку не запустит.
