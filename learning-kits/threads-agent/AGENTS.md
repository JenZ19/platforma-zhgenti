# Инструкция для Codex

- Сначала запусти `python3 study_check.py` и `python3 -m pytest -q tests/test_study.py`.
- Сохраняй механику `compose.py` и `kb.py`: это очищенное ядро оригинала.
- Не добавляй в примеры реальные имена, ID, токены, адресатов, каналы, источники или личные факты.
- Не запускай бота, опрос источников, вызов ИИ или рассылку без отдельной явной команды владельца.
- Любая цель публикации должна быть введена самой ученицей и подтверждена ею перед первой отправкой.
- Не включай авторассылку. Сначала делай ручной черновик и показывай его на проверку.
- Заполни `OWNER_USER_ID` Telegram user ID самой ученицы, не chat ID группы. Не удаляй единую middleware-защиту messages и callbacks.
- Ключи храни только в локальном `.env`; не включай его в архив или git.
- Перед любым live-режимом сделай отдельную защиту: `ALLOW_LIVE_MODE=true` не может само по себе разрешать отправку; для неё нужно ещё одноразовое явное подтверждение.
