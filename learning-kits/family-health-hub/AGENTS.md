# Учебная копия healthtablo

Прочитай START-HERE.md и RULES.md до запуска. Это оригинальный семейный хаб, не задача написать похожее приложение с нуля.

- Работай только в распакованной копии. Не открывай базы, документы и настройки других установок.
- Сначала отдельное виртуальное окружение и `python study_check.py`. Этот тест создаёт только вымышленные данные в новой папке. Существующую папку не удаляй: выбери другое имя через --output.
- Для просмотра учебного результата задай HUB_DATA_DIR и HUB_INBOX_DIR в абсолютные пути внутри study-output. Не наследуй внешние HUB_* из окружения. Сервер только 127.0.0.1, свободный порт. Отдельно объясни, что это адрес на компьютере, не ссылка для телефона.
- Для личного проекта создай другую пустую папку данных. Учебные числа не переносить в личную медицинскую историю. Настоящие PDF загружаются непосредственно в локальный хаб, не в чат и не во внешнюю модель.
- Никакой публикации в интернет, пушей и расписаний без отдельного согласия. Ключи, cookies и пароли не запрашивай в чате.
- После первого теста предложи название и оформление; не переписывай парсеры без проверочного документа. Все значения и единицы сверяются с оригиналом, неизвестные данные остаются неизвестными.
- Не ставь диагноз, не советуй лечение. Референс из бланка — не медицинское заключение. Не называй серверную установку соответствующей 152-ФЗ только из-за пароля или расположения сервера.
