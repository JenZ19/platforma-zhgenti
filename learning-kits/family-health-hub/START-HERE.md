# Семейный хаб здоровья — учебный комплект

Здесь настоящий код healthtablo: профили семьи, входящие документы, разбор PDF, история и графики. Чужих анализов, базы и паролей в комплекте нет.

## 1. Откройте папку в Codex

Распакуйте архив в отдельную папку. Откройте её как проект Codex и отправьте:

> Прочитай AGENTS.md и START-HERE.md. Проверь Python 3.11+ и свободное место, создай в этой копии виртуальное окружение. Сначала объясни, какие зависимости нужно скачать. После моего согласия установи их, выполни study_check.py и открой учебный хаб только на 127.0.0.1 со своей тестовой папкой данных. Не открывай мои настоящие документы, не используй другие установки и ничего не публикуй. Покажи результат проверки и ссылку.

Скачивание зависимостей требует интернета. Сам учебный импорт выполняется без сети и без API-ключа.

## 2. Посмотрите проверочный результат

Codex создаст папку `study-output`. В ней будут вымышленный PDF, отдельная база и отчёт `check-result.json`. В хабе откройте профиль «Я»: один учебный документ с двумя значениями. Повторный импорт того же PDF не создаёт второй документ.

PDF намеренно подписан `EDUCATIONAL FICTION`. Числа нужны только для проверки переноса, а не для оценки здоровья. Откройте исходный PDF и сравните **5.0** и **140**, названия и единицы с карточкой документа.

Если увидели ошибку, скопируйте её в тот же разговор с Codex. Не отмечайте запуск готовым, пока документ и значения не открываются.

## 3. Сделайте личную версию

> Учебная проверка прошла. Создай отдельную ПУСТУЮ папку для моей версии и запусти её на локальном адресе. Тестовые измерения не копируй. Помоги выбрать название и оформление, затем покажи, где добавить профиль и загрузить PDF непосредственно в хаб. Не проси медицинские документы в чате.

Начните с одного документа. Сверьте распознанные строки, дату, профиль и единицы с PDF. Неразобранные строки не заполняйте догадками. Хаб не ставит диагнозов и не назначает лечение.

## С телефона

Архив передаётся вашему школьному помощнику. Он должен подготовить отдельную **закрытую** установку с входом и резервной копией. Без неё локальная ссылка компьютера на телефоне не откроется. Пока доступ не выдан, выполняйте только подготовку, без настоящих медицинских файлов.

## Для Codex: команды и ограничения

```sh
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\python.exe
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -p 'test_study.py'
.venv/bin/python study_check.py
```

Для просмотра выставить абсолютные пути `HUB_DATA_DIR=<папка>/study-output/data`, `HUB_INBOX_DIR=<папка>/study-output/inbox`, `HUB_AUTH_FILE=<папка>/study-output/data/auth.json`, затем `.venv/bin/python hub.py serve --host 127.0.0.1 --port 8765`. При занятом порте выбрать другой, чужой процесс не останавливать.

Базовый путь — PDF с текстовым слоем. Распознавание сканов в оригинале использует macOS Vision; на Windows/Linux оно может быть недоступно. Не обещать OCR там, где он не проверен. Локальный доступ без пароля не означает готовность к публикации; для закрытого сервера нужна отдельная проверка доступа, хранения и резервного копирования.
