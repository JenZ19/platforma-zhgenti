# Инструкция для Codex

- Сначала выполни `python3 study_check.py` и тесты.
- При первой учебной проверке работай только с вымышленными данными из `examples/`.
- Во время учебной проверки не запускай webhook, polling, Telegram, GetCourse, Playwright или комнаты. Подключение личной версии — отдельный этап после явного разрешения пользователя, настройки только его доступов и согласования тестовой комнаты.
- Не пытайся найти или унаследовать `.env` из родительских папок.
- Храни режим `observe`, пока пользователь отдельно не попросит иное и не даст свои доступы.
- Не выдавай офлайн-демо за живого Telegram- или AI-агента.
- Любую новую логику сначала закрепи падающим тестом, затем внеси минимальную правку.
