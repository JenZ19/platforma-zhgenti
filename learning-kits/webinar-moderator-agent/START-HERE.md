# Модератор вебинара: учебный комплект

Это очищенная копия ядра реального авторского модератора. Она показывает, как
бот отсеивает реакции и спам, а также ищет похожий уже одобренный FAQ-ответ.
В `original_core/` лежит очищенный полный runtime: watcher, pipeline, Telegram-мост, scheduler,
сессия, конфигурация, FAQ-хранилище и подбор ответов.

## Первое действие

Передайте Codex эту папку и напишите:

> Прочитай AGENTS.md и START-HERE.md. Ничего не запускай в сети. Сначала покажи, что будешь устанавливать, и дождись моего согласия. После согласия создай локальное окружение, установи зависимости и запусти только study_check.py и тесты. Живой runtime не запускай.

## Команды для Codex

Выполнять самой не нужно. После вашего согласия Codex выполнит:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python3 -m pip install -r requirements.txt
   python3 study_check.py
   python3 -m unittest discover -s tests -p 'test_*.py'
   ```

Проверка читает только вымышленные файлы из `examples/`. Она не запускает Telegram,
GetCourse, webhook, polling, браузер или комнату. Режим по умолчанию — `observe`.

## Что попробовать

- Замените вымышленные вопросы в `examples/questions.json`.
- Добавьте свои вымышленные FAQ в `examples/faq.json`.
- Запустите `python3 study_check.py --json`, чтобы увидеть данные целиком.

Без AI-ключа исходная эвристика уверенно распознаёт лишь реакции, приветствия и спам.
Спорный вопрос получает честную метку `other/fallback`, а не выдуманный AI-ответ.

## Настоящая интеграция

`.env.example` показывает поля полного runtime. Для настоящего запуска нужны отдельные
собственные доступы, своя комната в `original_core/webinars.yaml` и калибровка. Ключи нельзя вставлять в учебные JSON
или переносить из рабочего бота. Настоящий запуск сначала оставляют в `observe`.
