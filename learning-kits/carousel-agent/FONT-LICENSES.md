# Шрифты

Все 15 включённых файлов шрифтов содержат во встроенной таблице `name` указание на SIL Open Font License 1.1. Полный официальный текст включён как `OFL.txt`; источник: <https://openfontlicense.org/documents/OFL.txt>.

Семейства: Caveat, Cormorant, Golos Text, Inter, JetBrains Mono, Manrope, Montserrat, Oswald, Playfair Display, Russo One и Unbounded. У Playfair Display зарезервировано имя «Playfair Display», у Russo One — «Russo»; при модификации шрифтов нельзя выпускать изменённую версию под зарезервированным именем.

Исходная папка бота не содержала отдельного файла OFL. В комплект он добавлен, а сведения об авторстве сохранены внутри файлов шрифтов.
