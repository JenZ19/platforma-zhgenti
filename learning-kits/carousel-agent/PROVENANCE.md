## Фактическая механика

В актуальном `STYLES` — 10 направлений: `editorial`, `poster`, `neon`, `pastel`, `notebook`, `swiss`, `fashion`, `retro`, `impact`, `classic`. Они дают 24 выбираемые палитры; всего в `THEMES` 30 записей, потому что у трёх impact-палитр есть по две внутренние темы для чередования. Бот отдельно предлагает `surprise`. Ранние формулировки «8» или «11 стилей» не соответствуют этому снимку.

## Изменения учебной копии

- Удалены личный ник, ссылка, имя авторского голоса и username рабочего бота; вместо них нейтральные значения пользователя.
- `carousel_generator.py` изменён только в одном комментарии: удалён внешний username-референс. Рендеринг не менялся.
- Добавлен закрытый по умолчанию доступ через числовые `ALLOWED_USER_IDS` / `ALLOWED_CHAT_IDS`; механизм взят из другого авторского форка без его значений.
- Перед чтением конфигурации очищаются унаследованные переменные Telegram/OpenAI/Qwen/транскрибации и allowlist; затем принимаются значения только из собственного `.env` комплекта через `dotenv_values`. `transcribe.py` больше не ищет родительский `.env`. Сессии и библиотека фото по умолчанию пишутся в `runtime-data/` комплекта; путь состояния оригинала явно запрещён.
- Добавлены `access_control.py`, безопасный `.env.example`, фиксированный вымышленный пример, офлайн-проверка, тесты и учебные инструкции.
- Оригинальный AI- и Telegram-код сохранён для изучения, но не вызывается офлайн-проверкой.
