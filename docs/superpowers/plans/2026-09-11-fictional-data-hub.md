# Учебные данные для Феечки

**Цель:** открытый `https://ezhgenti.ru/data/` с вымышленными данными для всех 49 маршрутов и прямыми ссылками в мобильных командах. Работа одним пакетом по просьбе владельца.

**Архитектура:** отдельный статический каталог, собранный из авторских таблиц и действующего реестра квестов. JSON и Markdown на каждый slug; CSV на каждую таблицу; два помеченных учебных PDF для здоровья. Без загрузки пользовательских данных, ключей, чатов и закрытых исходников курса. Не открывать `/kurs1/` и его ZIP.

**Интерфейс:** розовый акцент НЕЙРОПРОФИ, компактный заголовок, поиск, фильтры, карточки наборов, просмотр таблиц и кнопка копирования ссылки для Феечки. Данные видны без JavaScript, файлы скачиваются без входа. Явная маркировка вымысла и отдельные проверочные сценарии. Не показывать придуманные факты как отзывы или медицинские рекомендации.
