# Продолжение утверждённой переработки всех треков

Основание: пользователь одобрил планер и агента планирования и прямо просит применить исправления ко всем остальным маршрутам. Новое согласование концепции не требуется. Содержание перерабатывается группами, внутри группы — по одному проекту; результат группы проходит независимую проверку.

## Обязательные правила

- Первый результат — работающая основа, не повторное описание намерений. Для проектов на исходном шаблоне сначала проверяется его наличие; недостающий шаблон не выдумывается.
- Не просить ученицу создавать технические файлы. Короткая команда помощнику, отдельная ручная проверка продукта.
- Настройка собственной версии после создания; клиентская копия в дополнительном финальном блоке, не обязательна для завершения личной работы.
- Реальные данные не подменять учебными. Проверочные примеры отдельно; личные данные не публиковать.
- Мобильные команды направлены выданному помощнику школы, проверка — в созданном продукте. Никакого обязательного Codex на телефоне и случайного переноса в Lovable.
- Не менять обложки, дизайн, идентификаторы проектов. Не удалять старый прогресс: архивировать и переносить лишь подтверждённые этапы.
- Количество уроков соответствует проекту, а не единому шаблону. Не навязывать оплату, сервер, запись и интеграции там, где их не выбирали.
- Полезные реальные скриншоты сохранить; устаревшие вымышленные кадры не выдавать за новые результаты.

## Порядок и файлы

1. Бытовые сервисы: `app/content/reviewed/services.ts` и предметные тесты. Интерфейс `buildServiceLessons(project, mode, custom): ReviewedLesson[] | undefined`. Проверить каждый сценарий в тексте: ввод, изменение, ошибка, сохранение, отдельная демопубликация.
2. Агенты: `app/content/reviewed/agents.ts`. Интерфейс `buildAgentLessons(...)`. Предметные диалоги из существующих контрактов; подключение Telegram отделено от теста, нет непроверенных обещаний голоса и памяти.
3. Сайты, дизайн и портфолио: `app/content/reviewed/sites.ts`, `special.ts`. Новые сайты получают одну цель; продвинутые дорабатывают копию существующего. Четыре авторских продукта сохраняют исходную механику и явный запрос учебного шаблона.
4. Общая интеграция: `reviewed/shared.ts`, `reviewed/index.ts`, `quests.ts`, `mobile.ts`, счётчики и миграция прогресса. Сначала регрессионные тесты; затем изменение. Установка/сервер/API — предметная редактура существующих шагов с сохранением реальных снимков и проверенных ссылок.
5. Полный набор unit-тестов, lint, сборка, браузерные проверки разных групп на компьютере и телефоне. Публикация обратимым релизом на действующем `/kurs1/`, проверка живого HTML и браузера.
