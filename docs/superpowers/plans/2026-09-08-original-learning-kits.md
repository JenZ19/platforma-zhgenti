# Четыре оригинальных учебных комплекта

**Цель:** дать ученице настоящую очищенную рабочую копию авторского продукта, а не задание создать похожий проект.

**Решение:** отдельные каталоги `learning-kits/{carousel-agent,threads-agent,webinar-moderator-agent,family-health-hub}`. Копировать только явно проверенные исходники оригиналов. Добавить `START-HERE.md`, `AGENTS.md`, учебный пример и безопасную проверку без ключей. Источник, хеши и изменения записать в `PROVENANCE.md`. Затем ZIP и ссылка в первом уроке. Пользователь уже выбрал воспроизведение именно своих проектов и поручил изготовить эти комплекты; повторное согласование дизайна не требуется.

## Общие ограничения

- Оригинальные репозитории и работающие боты не изменять и не запускать.
- Не копировать `.env`, токены, базы, cookies, журналы, личные документы, фотографии, адресатов, историю, production deploy и частные голосовые паспорта. Никаких реальных данных в учебных примерах.
- Выбор файлов по разрешающему списку. Проверить и содержимое кода: там тоже возможны секреты, адреса и жёстко заданные личные параметры.
- Учебный запуск без сетевых запросов и оплаты. Настоящий режим отдельно, только после безопасной настройки собственных доступов. Не выдавать локальную демонстрацию за работающий Telegram или ИИ.
- Не выдумывать архитектуру вместо оригинала; допустимы минимальные безопасные конфигурационные изменения и отдельный учебный harness на оригинальных функциях.
- Ученица передаёт папку Codex. Технические действия выполняет Codex; START-HERE объясняет результат, тест, собственную настройку и ограничения. Для телефона нужен школьный помощник на сервере, не локальный localhost на телефоне.
- Все изменения локальных текстовых файлов — apply_patch. Копирование неизменённых разрешённых исходников и сборка архивов — механические операции.
- Работа пакетная, без новых вопросов кроме реального блокера. Существующие изменения других участников не откатывать. Коммиты не делать: текущий checkout содержит одобренную несохранённую работу.

## Контракт исполнителей

Каждый исполнитель владеет только своим `learning-kits/<slug>/` и отчётом `docs/audits/kit-<slug>.md`. Структура комплекта: оригинальный код, безопасный `.env.example` при необходимости, `START-HERE.md`, `AGENTS.md`, `PROVENANCE.md`, команда `python3 study_check.py` (в venv при внешних зависимостях), `tests/test_study.py`. Тест сначала красный, затем проверка реализации. В отчёте — точные команды и результаты, источник и изменения, ограничения настоящего запуска. Финальное сообщение короткое. Корень проекта и платформу меняет только основной исполнитель.
