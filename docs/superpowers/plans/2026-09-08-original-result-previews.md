# Примеры результата оставшихся учебных комплектов

Пользователь одобрил полный кадр реального результата Карусельщика и продолжение для остальных трёх комплектов. Повторное согласование оформления не нужно. Работа последовательно, без изменения оригиналов и подключений; только локальные изображения для просмотра, без смены обложек и деплоя платформы.

- Threads: прогнать существующий study_check в новой папке, прочитать созданный черновик из его SQLite; показать текст в отдельном листе просмотра, явно «не экран Telegram». Не рисовать кнопки/переписку не запущенного агента.
- Модератор: получить существующий JSON-отчёт без сети; показать фактические категории и результаты поиска FAQ, включая неопределённый ответ. Лист просмотра, не окно вебинара.
- Хаб: импортировать существующий вымышленный PDF в новой тестовой базе, запустить локальный оригинальный интерфейс на 127.0.0.1, снять профиль/документ без подмены DOM. Остановить только свой процесс.
- Проверка: тест HTML-экранирования и сохранения данных до реализации листов; затем открыть готовые страницы в браузере и снять целиком; посмотреть изображения перед передачей. Учебные примеры не выдавать за живые интеграции. Исходные комплекты и скачиваемые ZIP не изменяются.
