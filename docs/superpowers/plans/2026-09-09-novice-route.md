# Поддержка первого результата

Пользователь одобрил предложения аудита и поручил реализовать доступное без повторных согласований. Работаем в существующей платформе, сохраняем изображения, материалы и накопленный прогресс. Новые внешние интеграции без доступов не имитируем.

## План

- [x] Общий блок действия сразу после заголовка: место работы, копирование сверху, раскрываемая полная команда, ссылки комплекта перед копированием, ошибка буфера с ручным вариантом. Подключить в обоих форматах всех квестов.
- [x] Просмотр следующих шагов без записи выполнения; возврат к сохранённому месту. В режиме просмотра завершение недоступно, пропуск не приносит наград.
- [x] Помощь: редактируемый черновик с проектом, шагом и устройством; копирование для куратора без мнимой отправки. Не собирать секреты.
- [x] Главная: спокойное начало, настройки переноса свёрнуты отдельно от доступа с телефона, сервер/API не рекомендуются первым проектом. Подготовка подписана как подготовка, не сервис.
- [x] Готовая основа первого планера: автономный учебный HTML, ZIP и открываемый пример. Инструкция начинает с неё, затем меняет свою копию. Существующие проекты не заменяются.
- [x] Тесты до реализации, общий набор тестов, сборка, проверки в браузере, изолированный деплой /kurs1/ с откатом. Ограничение старого dev-теста и замещающие production-проверки описаны в аудите.
- [x] Личный список владельцу: выдача мобильных рабочих мест, реальная защищённая панель ключей, контакт и регламент куратора, бюджет и правила AI-помощника, испытание с новичками. Отдельно назвать оставшиеся программные улучшения, не перекладывать их на владельца.

## Границы

Просмотр урока не проверяет внешнее приложение. Доступы школы не подтверждаются по одному сохранению Telegram-ссылки. ИИ-ответы и отправка куратору не заявляются подключёнными. Никакие покупки не производятся. Не меняем идентификаторы прогресса и не делаем массовый commit чужих изменений.
