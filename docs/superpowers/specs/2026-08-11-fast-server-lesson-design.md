# Быстрый урок «Покупаем сервер по 152-ФЗ»

## Задача

Урок должен провести новичка от решения «сервер нужен» до готового доступа без десятков повторяющихся экранов. Большие служебные галереи Академии в этом квесте не показываются.

## Новый маршрут

Вместо 17 уровней остаются 8:

1. Понять, нужен ли сервер, и кто оператор данных.
2. Открыть AdminVPS, выбрать Россию и подходящий VPS.
3. Применить промокод SUBMARINE123 и проверить итог.
4. Зарегистрироваться и оплатить без передачи секретов.
5. Найти Active-сервер, IP и дату следующей оплаты.
6. Передать Codex безопасное задание на SSH-настройку и защиту.
7. Включить резервные копии и сохранить полный PDF как справочник.
8. Пройти короткую юридическую границу: сервер не равен полному соответствию 152-ФЗ, проверить документы, Роскомнадзор и внешние API.

## Визуальный принцип

- Ноль трёхкадровых галерей «Откройте — сделайте — сверьте».
- Один прототип экрана только там, где он помогает узнать интерфейс AdminVPS: выбор VPS, промокод, оплата, карточка сервера.
- На смысловых шагах вместо изображения остаётся короткий список «Готово, если».
- Полная шестистраничная инструкция остаётся доступна отдельной ссылкой как справочник.

## Совместимость

Остальные квесты продолжают содержать 17 уровней. Прогресс, карточки, статистика, компьютерная и мобильная версии должны использовать фактическое количество уровней выбранного квеста.
