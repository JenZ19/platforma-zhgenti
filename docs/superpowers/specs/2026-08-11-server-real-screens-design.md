# Реальные экраны в квесте про VPS — дизайн

## Цель

Убрать из квеста «Покупаем сервер по 152-ФЗ» все синтетические изображения, похожие на интерфейс AdminVPS. Ученица должна видеть настоящий экран, с которым встретится на сайте, либо честную заглушку для будущей замены.

## Карта восьми уровней

1. «Решила, нужен ли мне сервер» — скриншот не нужен: это два вопроса до покупки.
2. «Выбрала сервер в России» — актуальный реальный экран открытой страницы AdminVPS: выбрана Россия, видны тарифы и кнопки «Заказать».
3. «Применила скидку 60%» — реальный предоставленный скрин корзины с промокодом `SUBMARINE123` и пересчитанной суммой.
4. «Оформила и оплатила сервер» — реальный экран формы оформления из PDF-инструкции, без введённых платёжных секретов.
5. «Нашла IP и дату оплаты» — реальный экран карточки/списка сервера из PDF-инструкции.
6. «Передала настройку Codex» — реальный экран раздела «SSH-ключи» из PDF-инструкции.
7. «Включила резервную копию» — явная заглушка «Добавим реальный скрин раздела “Резервные копии”», потому что точного экрана в доступных материалах нет.
8. «Проверила границы 152-ФЗ» — скриншот не нужен: это юридический чек-лист, а не экран AdminVPS.

## Как помечаются изображения

- настоящий интерфейс получает подпись «реальный экран»;
- заглушка получает подпись «заглушка для замены»;
- реальные скриншоты показываются целиком через `object-fit: contain`, без обрезки важных кнопок и полей;
- в модальном просмотре сохраняется тот же оригинальный файл;
- изображения из личного кабинета используются только из предоставленной пользователем инструкции.

## Обучающие определения

На первом уровне до вопросов появляется объяснение:

> Сервер — это отдельный компьютер в дата-центре. Он работает круглосуточно, хранит файлы и данные проекта и делает сайт, сервис или ИИ-агента доступным пользователям через интернет. Покупка сервера решает только техническую задачу размещения и сама по себе не означает соответствие 152-ФЗ.

На шестом уровне перед инструкцией появляется объяснение:

> SSH-ключ — безопасный способ дать вашему компьютеру или Codex доступ к серверу без пересылки пароля. У ключа две части: публичная похожа на замок — её можно добавить в AdminVPS; приватная похожа на единственный ключ от этого замка — она остаётся только на вашем компьютере. Файл `.pub` можно копировать в AdminVPS, `PRIVATE KEY` нельзя отправлять в чат, Академию или заказчику.

## Критерии готовности

1. В уровнях 2–6 нет сгенерированных интерфейсных прототипов.
2. Уровень 7 явно показывает заглушку, а не выдаёт её за результат.
3. Уровни 1 и 8 не требуют бессмысленного скриншота.
4. Определения сервера и SSH-ключа видны до действия, написаны простыми словами и разбиты на абзацы.
5. Компьютерная и мобильная версии показывают изображения полностью и без горизонтальной прокрутки.
