# Режим данных перед каждым квестом

## Цель

Перед первым уровнем каждого из 52 квестов участница отдельно выбирает, делает ли она учебный проект на вымышленных данных или реальный проект на своих/клиентских материалах.

## Пользовательский сценарий

1. При первом открытии квеста показывается стартовый экран «На каких данных будем работать?».
2. «Вымышленные данные» сохраняет учебный режим для этого квеста и сразу открывает 17 уровней с готовыми примерами.
3. «Реальные данные» открывает персональный чек-лист проекта: что собрать, что положить в папку и что нельзя туда добавлять.
4. Каждый пункт чек-листа отмечается отдельно. Кнопка «Папка готова — начать квест» недоступна, пока не отмечены все пункты.
5. После подтверждения открываются 17 уровней. Команды Codex переключаются на материалы из подготовленной папки и не требуют вымышленных примеров.
6. Режим, отметки чек-листа и готовность сохраняются отдельно по slug каждого проекта в localStorage.
7. «Начать этот квест заново» сбрасывает прогресс, выбранный режим и чек-лист только текущего проекта.

## Чек-листы

Чек-лист строится из типа проекта и его конкретных сущностей, функций и правил безопасности. В каждом реальном проекте есть:

- отдельная папка и только копии материалов;
- конкретные исходные данные для этого проекта;
- тексты, названия, примеры или сценарии, необходимые именно ему;
- разрешённые фотографии/визуалы, если они нужны;
- подтверждённые публичные контакты, цены и условия, если применимо;
- обязательная проверка правила безопасности проекта;
- запрет на пароли, токены, банковские реквизиты, документы личности и лишние персональные данные.

## Команды Codex

Учебный режим сохраняет текущие команды и демонстрационные примеры. Реальный режим добавляет к каждой команде правило сначала читать подготовленные материалы, не додумывать отсутствующие факты, задавать один простой вопрос при нехватке данных и не публиковать закрытые исходники. Противоречащие фразы про «только вымышленные примеры» заменяются на инструкции по безопасным реальным материалам.

## Интерфейс

Стартовый экран является «нулевым шагом» внутри существующей страницы квеста и сохраняет стиль SUBMARINE. На телефоне карточки выбора и пункты чек-листа идут одной колонкой, зона нажатия не меньше 44 px. До завершения подготовки карта уровней не показывается.

## Проверка

- выбор и чек-лист изолированы по проектам;
- учебный режим открывает уровни сразу;
- реальный режим блокирует старт до всех отметок;
- повторный вход восстанавливает режим;
- сброс возвращает стартовый выбор;
- команды реального режима не содержат требования использовать вымышленные примеры;
- мобильная ширина 390 px не имеет горизонтальной прокрутки.
