# Короткий квест «Устанавливаем Codex»

## Цель

Заменить перегруженный путь из 17 уровней короткой инструкцией, в которой ученица сначала выбирает Mac или Windows, затем видит только подходящую ветку и за шесть уровней устанавливает приложение, открывает Codex и получает первый видимый результат.

## Утверждённый сценарий

Перед началом уровней показывается отдельный экран выбора компьютера: «Mac» или «Windows». Выбор сохраняется на устройстве и может быть сброшен вместе с проектом.

После выбора открываются шесть уровней:

1. Скачать официальное приложение.
2. Установить приложение и войти в ChatGPT.
3. Выбрать Codex в верхнем левом меню.
4. Открыть отдельную учебную папку проекта.
5. Отправить готовую команду на создание тестовой страницы.
6. Открыть результат и убедиться, что Codex готов к курсу.

## Тексты и изображения

- Не объяснять, как определить Mac или Windows по значкам.
- Не заставлять проходить или отмечать чужую ветку.
- Не добавлять отдельную проверку совместимости как уровень; краткое требование macOS 14 оставить примечанием в ветке Mac.
- Не создавать галерею из трёх повторяющихся кадров для каждого уровня.
- На каждом уровне показывать не более одного изображения.
- Использовать реальный экран официальной страницы загрузки там, где его можно получить достоверно.
- Если достоверного снимка системного окна или интерфейса нет, использовать явно подписанную заглушку для последующей замены, а не выдуманный интерфейс.
- Ссылки вести только на официальные страницы OpenAI.

## Хранение и сброс

Выбор платформы хранится отдельно для компьютерной и мобильной версии. Сброс квеста удаляет прогресс текущей ветки и возвращает ученицу к выбору Mac или Windows. Прогресс других проектов не изменяется.

## Проверка

- Mac и Windows создают разные инструкции на первых двух уровнях.
- В обеих ветках ровно шесть уровней.
- В тексте нет объяснения про яблочко, четыре квадрата, записи на листке или просьбы пропустить чужую ветку.
- Повторяющаяся галерея «Делайте по картинкам» отсутствует.
- Выбор платформы восстанавливается после перезагрузки и сбрасывается только внутри этого квеста.
- Оба пути работают на широком и узком экране.
