# Каталог по сложности и полный путь AdminVPS

## Цель

Помочь ученице без технического опыта быстро выбрать посильный квест и пройти покупку российского VPS без расхождений между уроком, провайдером и скриншотами.

Изменение состоит из двух связанных частей:

1. Каталог сохраняет порядок курса по неделям, а внутри каждой недели показывает проекты от лёгких к сложным.
2. Квест «Покупаем сервер по 152-ФЗ» использует AdminVPS как основной практический путь, полностью повторяет приложенную шестистраничную инструкцию и показывает партнёрскую скидку.

## 1. Ранжирование и выбор квеста

### Порядок каталога

- Главная ось остаётся прежней: неделя 1 → неделя 6.
- Внутри недели карточки сортируются по сложности, затем сохраняют стабильный исходный порядок.
- При выборе конкретной недели показывается тот же порядок от лёгких к сложным.
- Поиск и фильтры не меняют оценку сложности, а только скрывают неподходящие карточки.

### Четыре уровня сложности

| Балл | Подпись на карточке | Что это означает для ученицы |
| --- | --- | --- |
| 1 | Стартовый | Можно начинать с нуля; один понятный результат без внешних подключений. |
| 2 | Лёгкий | Несколько экранов или простая логика; готовые команды ведут через весь путь. |
| 3 | Средний | Есть публикация, интеграция, внешний сервис или более длинная проверка. |
| 4 | Продвинутый | Есть сервер, платежи, персональные данные, несколько систем или повышенная цена ошибки. |

Сложность назначается вручную каждому конкретному пути, а не вычисляется только по неделе или типу проекта. Это не оценка способностей ученицы, а предупреждение о количестве действий и риске ошибки.

У объединённой карточки «Сервис или ИИ-агент» показывается диапазон двух путей, например «Стартовый → Лёгкий». Для сортировки используется более лёгкий путь. При фильтрации по сложности карточка подходит, если выбранный уровень входит в её диапазон.

### Ключевые слова

Каждый проект получает от двух до пяти внутренних ключевых слов. На карточке видны не более трёх, чтобы она оставалась лёгкой для чтения.

Основные фильтры:

- Для себя
- Семья и быт
- Здоровье
- Контент
- Для клиентов
- Для заработка
- Сайты и сервисы
- ИИ-агенты
- Настройка

Поиск учитывает название, результат, направление и все ключевые слова. Например, запросы «мама», «ребёнок», «семья» и «дом» находят бытовые проекты, даже если точное слово отсутствует в названии.

### Интерфейс

Над карточками располагаются три последовательных выбора:

1. Неделя.
2. Сложность: «Любая», «Стартовый», «Лёгкий», «Средний», «Продвинутый».
3. Цель: один из ключевых фильтров.

Рядом находится кнопка «Сбросить выбор», которая возвращает все недели, любую сложность и все цели. Заголовок сообщает количество найденных проектов. Если ничего не найдено, интерфейс предлагает сбросить фильтры, а не только изменить поисковую строку.

На компьютере сложность видна отдельной цветной плашкой на карточке. На телефоне фильтры листаются горизонтально пальцем, а плашка сложности располагается рядом со статусом проекта.

### Данные и границы

Новый модуль discovery хранит для каждого конкретного пути:

- числовую сложность 1–4;
- короткую подпись;
- список ключевых слов;
- поисковые синонимы.

Каталожные карточки получают сводный профиль через отдельную функцию. Состояние фильтров хранится только в интерфейсе текущей страницы и не изменяет прогресс квестов.

## 2. Квест «Покупаем сервер по 152-ФЗ»

### Основной провайдер

AdminVPS становится основным практическим провайдером этого квеста. Selectel больше не используется в пошаговых действиях, чтобы ученица не покупала сервер в одной панели и не искала кнопки другой панели. Ссылка на официальный материал Selectel о распределении ответственности остаётся только как дополнительный источник в юридическом пояснении; кнопок и экранов панели Selectel в практическом маршруте не будет.

### Партнёрский блок

После объяснения, кому действительно нужен сервер, показывается заметный блок:

- заголовок «Скидка 60% на сервер для ваших проектов»;
- объяснение, для каких курсовых проектов нужен VPS;
- кнопка «Перейти на AdminVPS» с адресом `https://adminvps.ru/`;
- промокод `SUBMARINE123` с отдельной кнопкой копирования;
- приложенный скриншот корзины со скидкой;
- условия: один сервер, одна активация, один месяц, все тарифы кроме Lite;
- короткая проверка перед оплатой: в корзине должна появиться скидка 60%, а итоговая сумма должна обновиться.

Рядом всегда остаётся предупреждение: скидка не подтверждает юридическое соответствие проекта 152-ФЗ. Для персональных данных выбирается российская локация, а оператор отдельно выполняет правовые, организационные и технические обязанности.

### Полный маршрут из PDF

Содержание приложенной инструкции переносится без пропусков и распределяется по квесту так:

| Уровень | Содержание |
| --- | --- |
| 1 | Определить, собирает ли проект персональные данные и нужен ли рабочий сервер сейчас. |
| 2 | Назвать оператора персональных данных. |
| 3 | Понять, что российский сервер — только часть требований статей 18 и 19 152-ФЗ. |
| 4 | Подготовить интернет, браузер, банковскую карту, рабочий email и 5–10 минут; открыть партнёрский блок. |
| 5 | Открыть `adminvps.ru`, проверить адрес, увидеть баннер текущей акции и блок дата-центров VPS. Показать перечисленные в PDF локации: Россия, Беларусь, Казахстан, Нидерланды, Германия, Финляндия и Польша. Объяснить, что при переносе сайта стоит отдельно проверить условия текущей акции. |
| 6 | Открыть «Выбрать виртуальные серверы», выбрать российскую локацию, сравнить Promo, Micro, Start и Standard, затем нажать «Заказать». Полностью показать справочные значения из PDF: Promo — 499 руб./мес., 1×3,5 ГГц CPU, 2 ГБ RAM, 15 ГБ NVMe; Micro — 799 руб./мес., 2 CPU, 4 ГБ RAM, 30 ГБ NVMe; Start — 1289 руб./мес., 4 CPU, 8 ГБ RAM, 60 ГБ NVMe; Standard — 2149 руб./мес., 8 CPU, 12 ГБ RAM, 100 ГБ NVMe. Рядом явно написать, что это значения на экране исходной инструкции и перед оплатой нужно сверить живую страницу. Для теста PDF рекомендует Promo. |
| 7 | Проверить корзину: тариф, российскую локацию и операционную систему; пояснить, что в PDF по умолчанию показана Ubuntu 22.04. Показать дополнительные память, диск, IP-адрес и еженедельный бэкап, которые для старта можно не подключать. Ввести `SUBMARINE123`, нажать «Применить», увидеть скидку 60%, проверить сумму и нажать «Оформить». |
| 8 | Выбрать тип клиента, заполнить имя, телефон и email, придумать пароль, выбрать оплату российской картой и осознанно решить, сохранять ли карту для автопродления. |
| 9 | После оплаты войти на `my.adminvps.ru`, открыть «Услуги» → «Продукты и услуги», найти карточку сервера и записать основной IP-адрес без публикации паролей. Если идёт переустановка системы или генерация пароля, дождаться окончания до подключения. |
| 10 | Дождаться статуса «Активный», проверить цену и дату следующего платежа. Показать доступные разделы: Серверы, Хостинг, Домены, SSL-сертификаты, Лицензии, Мониторинг, SSH-ключи и DNS-хостинг. В меню «Действия» показать перезагрузку, включение/выключение, смену тарифа и настройку бэкапов, но не запускать рискованное действие без необходимости. |
| 11 | Открыть раздел «SSH-ключи», нажать «Добавить» и вставить только публичную часть ключа. Если пары ключей ещё нет, перейти к следующему уроку по генерации. Сохранить ссылку AdminVPS «Добавление своего ключа SSH для VPS». Приватный ключ не копируется в квест или переписку. |
| 12 | Полностью пройти блок «Что важно не забыть»: сохранить пароли безопасно, записать IP, проверить дату платежа, настроить SSH-ключ, отключить парольный вход и менять тариф без пересоздания сервера. |
| 13 | Попросить Codex обновить и защитить сервер, создать отдельного пользователя, закрыть лишние порты и показать проверку без секретов. |
| 14 | Включить резервные копии и запланировать безопасную проверку восстановления. |
| 15 | Сверить документы AdminVPS по 152-ФЗ и зафиксировать роль провайдера; не подменять ими документы оператора. |
| 16 | Собрать чек-лист оператора: цель, основание, категории данных, политика, срок хранения, доступы, ответственные и уведомление Роскомнадзора. |
| 17 | Проверить внешние API, страны обработки и трансграничную передачу; завершить честной формулировкой без обещания полного соответствия только из-за сервера. |

Пример с Финляндией из PDF сохраняется только как объяснение влияния локации на задержку. В практическом действии этого квеста ученица выбирает Россию, потому что маршрут предназначен для проектов с персональными данными российских пользователей.

### Материалы

- Оригинальный PDF копируется в публичные материалы и доступен по кнопке «Скачать полную инструкцию».
- Приложенный скриншот скидки используется в партнёрском блоке и на уровне корзины.
- Все AdminVPS-уровни получают новые отдельные итоговые изображения и три пошаговых кадра.
- Компьютерный и мобильный варианты используют одинаковые формулировки, но мобильный честно сообщает, что покупку и настройку безопаснее завершать на компьютере.

## 3. Проверки

Автоматические проверки должны подтверждать:

- каждый конкретный квест имеет сложность и минимум два ключевых слова;
- внутри каждой недели карточки отсортированы по возрастанию сложности;
- поиск находит проект по ключевому слову и синониму;
- фильтры недели, сложности и цели работают совместно;
- объединённый проект корректно показывает диапазон сложности;
- квест AdminVPS содержит все семь разделов PDF и финальный чек-лист;
- промокод, условия, партнёрская ссылка и предупреждение о 152-ФЗ видны в компьютерном и мобильном варианте;
- ни один шаг не просит прислать пароль, приватный SSH-ключ или платёжные данные;
- все новые PNG существуют, имеют ожидаемый размер и отображаются без обрезания.

После модульных тестов выполняются сборка, визуальная проверка каталога на широком и мобильном экранах, полный проход квеста AdminVPS, проверка партнёрской кнопки и производственный деплой в существующий проект Sites.
