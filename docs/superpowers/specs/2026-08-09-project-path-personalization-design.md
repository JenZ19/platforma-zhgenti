# Персонализация всех проектных путей

## Проблема

Чек-лист реального проекта и часть шагов квеста строятся общим шаблоном по типу проекта. Из-за этого «Дневник давления» просит логотип, цены и контакты, а реальные действия превращаются в абстрактное «возьмите материал из папки». Такая подстановка не объясняет новичку, что именно открыть, создать, записать и проверить.

## Результат

Каждый из 52 проектов получает собственную памятку материалов. Памятка отвечает на четыре вопроса без технических слов:

1. Какую папку создать.
2. Какие файлы положить в папку и что написать внутри.
3. Зачем нужен каждый файл.
4. Как понять, что пункт выполнен.

Реальный квест называет конкретный файл, пример и действие текущего проекта. Он не добавляет одинаковую фразу перед каждым уровнем и не упоминает материалы, которые этому проекту не нужны.

## Модель содержания

Для каждого `slug` хранится отдельный профиль подготовки:

- понятное название рабочей папки;
- шесть предметных пунктов с названием, объяснением, последовательностью действий, примером и критерием готовности;
- отдельная проверка безопасности;
- отдельная проверка секретов;
- конкретные названия файлов и примеры строк.

Профили разбиты по неделям курса, чтобы один файл не превратился в нечитаемый каталог. Общий генератор только добавляет одинаковую структуру карточки, но не придумывает содержание.

## Правила по типам проектов

- Бытовые сервисы: личные записи, категории, фильтры, выгрузка. Без логотипа, цен и контактов, если проект их не использует.
- Боты: реальные вопросы, точные ответы, кнопки, ветки и безопасная тестовая переписка.
- Агенты: источники знаний, правила ответа, примеры хорошего результата и список запретов.
- Простые сайты: тексты разделов, фотографии с разрешением, услуги, условия и публичный контакт.
- Сложные сайты: каталог или услуги, формулы, формы, статусы и только тестовые платежи.
- Портфолио: свои работы, честные описания, роль, ссылки и разрешённые скриншоты.

## Реальный режим

Адаптер реального режима перестаёт механически подменять каждую демонстрационную фразу словом «материал». Вместо этого он:

- один раз добавляет к команде правило читать подготовленные файлы;
- сохраняет понятное действие уровня;
- заменяет учебный пример на конкретный пример из профиля проекта;
- не добавляет фразу про папку к проверке телефона, публикации, оформлению и другим действиям, где папка не нужна.

## Проверка

Автоматический аудит проходит все 52 проекта в обоих режимах и проверяет:

- у каждого проекта восемь подробных и уникальных пунктов;
- каждый пункт содержит шаги, пример или точный критерий готовности;
- ни один бытовой или медицинский сервис не просит цены, контакты и логотип без необходимости;
- «Дневник давления» просит дату, время, верхнее и нижнее давление, пульс, самочувствие и выгрузку для врача;
- медицинские проекты не оценивают здоровье и не дают рекомендаций;
- реальный режим не содержит механического «возьмите подходящий материал»;
- все 52 маршрута сохраняют 17 уровней и проходят сборку.
