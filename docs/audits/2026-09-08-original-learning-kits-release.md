# Оригинальные учебные комплекты — релиз

8 сентября 2026 года. Опубликованы четыре очищенных исходных комплекта версии 2026-09-08.1. Ссылки добавлены в первые шаги carousel-agent, threads-agent, webinar-moderator-agent и family-health-hub. Утверждённое оформление не менялось.

## Что проверено

- ZIP собираются только по явному package-files.json. Секреты, рабочие базы, cookies, журналы и deploy не включены. Внутренний KIT-MANIFEST.json содержит SHA-256 каждого файла; публичный manifest.json — SHA-256 ZIP.
- Финальные архивы распакованы в новый `/tmp/neiroprofi-kit-verified.dxmheS`; все файлы совпадают с исходниками и манифестом.
- Карусельщик: 5 тестов; исходный рендерер создаёт 4 PNG 1080×1350 с вымышленным контентом. Урок исправлен: 10 направлений + «Сюрприз»; платный Qwen не обязателен. Число AI-слайдов учитывает добавление CTA.
- Threads: 7 тестов; исходные compose/SQLite проверены без сети, повторный запуск не удаляет базу. Полный runtime включён. OWNER_USER_ID проверяется для всех сообщений и callback; чужие команды не меняют адресата/базу. Неиспользуемый AUTO_SEND удалён из примера.
- Модератор: 4 теста; исходные эвристики и FAQ, физическая блокировка сетевых вызовов. Полный runtime включён, реальные комнаты/сессии отсутствуют. По умолчанию observe, live opt-in только из локального файла.
- Хаб: 2 теста; исходный импорт вымышленного PDF сохраняет два точных значения и блокирует дубликат. Личная база не используется; интерфейс проверен локальным HTTP 200.
- Упаковщик: 3 теста, в том числе запрет .env, симлинков, traversal, баз и токенов; разрешён явно выбранный вложенный .env.example.
- Платформа: 621 unit-тест прошёл, lint и production build успешны.
- Браузер: все 4 ссылки видны и скачивают ZIP при ширинах 390 и 1440, без горизонтального переполнения. Проверено локально и на опубликованном домене.
- Живые четыре ZIP: HTTP 200, точные хеши совпадают; HTML совпадает с подготовленным релизом.
