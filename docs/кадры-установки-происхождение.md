# Настоящие экраны для квеста установки

Подготовлено 13 сентября 2026 года. В папке есть полный комплект из десяти основных кадров и один дополнительный.

Важно: `real-mac-step-02.jpg` и `real-mac-step-06.jpg` сняты в живом окружении Mac. Остальные восемь файлов с именами `real-*.jpg` сгенерированы как учебные макеты по просьбе владелицы. Они похожи на интерфейс, но не подтверждают фактическую установку и могут отличаться от текущей версии приложения.

## Что готово

| Файл | Содержание |
| --- | --- |
| `real-mac-step-02.jpg` | Настоящее окно официального ChatGPT Installer: значок ChatGPT, стрелка и папка Applications. |
| `real-mac-step-02-downloads.jpg` | Дополнительное окно Finder: поиск файла Codex.dmg внутри «Загрузок». Остальные файлы и боковая панель скрыты. |
| `real-mac-step-06.jpg` | Учебная страница, открытая в отдельном окне Google Chrome на Mac. Видны «Codex работает» и кнопка «Я готова». Аватар профиля закрашен. |
| `real-mac-step-03.jpg` | Сгенерированный макет ChatGPT после входа с выбранным разделом Codex. |
| `real-mac-step-04.jpg` | Сгенерированный макет диалога «Открыть папку» с выбранной `codex-test`. |
| `real-mac-step-05.jpg` | Сгенерированный макет поля Codex с полной учебной командой. |
| `real-win-step-02.jpg` | Сгенерированный макет установщика Windows и результата поиска ChatGPT в меню «Пуск». |
| `real-win-step-03.jpg` | Сгенерированный макет ChatGPT для Windows с выбранным Codex. |

| `real-win-step-06.jpg` | Сгенерированный макет браузерного предпросмотра для Windows. |

Для шага 2 сделаны два отдельных кадра, чтобы выполнить требование «одно окно на снимке».

Все JPG имеют ширину 1500 px. Инструмент захвата вернул исходники шириной 660 px для установщика, 920 px для Finder и 1342 px для Chrome. Изображения увеличены до требуемой ширины с сохранением пропорций; это не нативная съёмка в 1500 px. Окна и надписи не дорисовывались. WebP не создавался.

Официальный образ скачан по ссылке со [страницы приложения OpenAI](https://learn.chatgpt.com/docs/app): `https://persistent.oaistatic.com/codex-app-prod/Codex.dmg`. Его имя — Codex.dmg, название внутри — ChatGPT Installer. Контрольная сумма образа проверена через hdiutil: VALID. Установленное приложение не заменялось.

## Учебная страница

`codex-test/index.html` — автономный файл, созданный Codex в этой задаче по тексту из квеста. Его можно открыть двойным щелчком. Пакеты не нужны. Кнопка «Я готова» проверена в браузере: появляется сообщение «Всё получилось! Можно переходить к следующему квесту.»

`Учебная команда.txt` — точная команда из шага 5 квеста. Кадр 6 показывает результат в Chrome, а не встроенную панель предпросмотра приложения Codex. Он не подтверждает повторное прохождение входа и выбора папки.

## Ограничение макетов

Для публикации в квесте с подписью «Сверь свой экран с примером» сгенерированные файлы подходят как ориентиры. Их нельзя описывать ученице как настоящие скриншоты текущей версии приложения. Если позже появятся живые кадры, ими следует заменить восемь сгенерированных файлов с теми же именами.

## Передача в курс

Файлы подготовлены в этой папке. Репозиторий курса, `public/screens/install-codex/` и `app/content/setup-quests.ts` в этой задаче не изменялись.

При подключении все файлы можно использовать как визуальные ориентиры. Для двух снятых кадров допустим `screenshotKind: "real"`. Для восьми сгенерированных кадров лучше добавить отдельный вид `generated` или подпись «Пример экрана — интерфейс может отличаться». Если код пока поддерживает только `real` и `placeholder`, не помечать сгенерированные макеты как документальное подтверждение живого интерфейса.
